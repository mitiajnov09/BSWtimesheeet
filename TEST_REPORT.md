## Не проверено / ограничения

- Автоматическая проверка интерфейса, клавиатурных действий, планшетной компоновки и перетаскивания мышью не выполнена. Браузерный инструмент дважды отклонил локальный адрес, во второй раз — из-за сохранённой настройки разрешений, несмотря на явное согласие пользователя. Обход не выполнялся. Для просмотра доступен http://127.0.0.1:8080.
- Обновления других пользователей загружаются кнопкой обновления; живого обмена изменениями пока нет. Конфликты защищены на сервере.
- Перенос мышью предлагает даты в форме; окончательное сохранение подтверждается пользователем. Следующие периоды можно сдвигать при неизменной длительности выбранного; ручные исключения остаются на прежних датах.
- Для вставки отпуска/больничного внутрь существующего периода нужно сначала освободить диапазон через форму. Автоматического разделения через единую форму отпуска пока нет.
- Контейнеры, реальное размещение, HTTPS и восстановление на рабочем сервере не выполнялись. Подготовлены Docker, Compose и Caddy; финальная эксплуатационная проверка нужна после выбора сервера.
- Текущая база SQLite предполагает один сервер с постоянным локальным диском. Многосерверное размещение и PostgreSQL потребуют отдельной доработки.
- Регулярный запуск резервного копирования ещё не настроен: это задача будущего размещения.
- Публикация не выполнялась по указанию пользователя.
